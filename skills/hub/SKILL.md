# hub — 手上在跑的那幾件事

`HUB.md` 是開場提醒的來源。`SessionStart` hook 跑 `.claude/hooks/audit.py --hook`，
把這張表唸出來，逾期的標紅。

## 格式（硬規約，不要改欄名）

一件事 = 一個 `## ` 標題，底下固定四欄：

```markdown
## <這件事叫什麼>

- **現在做到哪**：一句話，要有具體狀態，不要寫「進行中」
- **東西放在哪**：路徑、網址、Notion 頁、repo 名
- **下一步**：一個具體動作。一次性的到期日寫在這裡
- **下次碰它**：YYYY-MM-DD
```

- `grep -c '^## ' HUB.md` 就是主線條數（SETUP §0.6 用它）。
- `audit.py` 靠「下次碰它」那行抓日期判逾期，日期一律 `YYYY-MM-DD`。
- 一次性的到期日**不要去建排程**，寫在「下一步」就好。

## 平常怎麼維護

| 他說了什麼 | 你做什麼 |
|---|---|
| 某件事有進展 | 改「現在做到哪」＋重設「下次碰它」 |
| 某件事做完了 | 問他要不要收掉；收掉就整段刪，別留著變雜訊 |
| 開始一件新的 | 新增一條，四欄問齊再寫 |
| 「上次那個」 | 先看這張表，對不上再去翻 `Sessionlog/` |

**2–3 條是健康的。** 超過五條就問他哪幾條其實已經停了——
一張十條的表跟沒有表一樣，開場提醒會變成他直接略過的雜訊。

## 建表（SETUP §2）

1. 讀 `Sessionlog/` 最近 2–4 週，歸納他手上 2–3 件在跑的事，各寫成四欄草稿。
2. **逐條唸給他聽**，改到他點頭為止。沒有舊對話可讀就直接問：「你最近同時在忙哪幾件事？」
3. 寫進 `HUB.md`，**把「示範條目」那條整段刪掉**。
4. 請他關掉重開一次對話（用 Claude 和 Codex 的話各開一次），開場應該會看到那張表。
   Codex 那邊沒看到 → 回去檢查 `install_codex_hook.py check`，以及他有沒有按過信任。

驗證：`python3 ".claude/hooks/audit.py"` 有輸出且沒有警告（剛寫的條目不會逾期）。
