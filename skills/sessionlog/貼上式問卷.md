# 貼上式問卷 — 給用 ChatGPT／Gemini 的人

**不要帶他去匯出。** 兩家的匯出都是「申請 → 寄信 → 下載 zip」，幾小時到一天，
開機第一個三十分鐘拿不到；而且本包沒有那些格式的匯入工具。

他要的不是原始紀錄，是結論，而那台 AI 已經知道了。

## 怎麼用

1. 把下面「給使用者複製的那段」**原樣**給他。
2. 他貼給 ChatGPT／Gemini。
3. **請他自己先看過再貼回來**——有不想給的直接刪掉，缺一兩段不影響。
4. 五題各自進對應的節（對照表在最後）。

⚠ **答案全部當「待確認」。** 那台 AI 沒有義務對你的系統負責，它會為了把版面填滿而編。
每一條都要唸給他聽、他點頭才寫檔。這跟讀 transcript 是同一個標準，不因為來源換了就放寬。

⚠ 他回報「ChatGPT 說它讀不到歷史對話」→ **不要叫他再試一次**，直接改走 SETUP §0 的分支 D（改成問他）。

## 給使用者複製的那段

```
請根據你對我的了解，回答下面五題。
不確定的就寫「不確定」，不要猜、不要為了填滿而編。
每題如果能引用我自己講過的原話，請附上一兩句。

1. 我手上同時在跑哪幾件事？每件事現在大概做到哪？
2. 我接下來三個月最想達成什麼？如果我講過具體的數字或日期，請一起寫出來。
3. 我平常重複在做、而且好像有點煩的事情有哪些？大概多久做一次？
4. 我的檔案和筆記都放在哪裡？（例如 Notion、Google 雲端硬碟、Obsidian、備忘錄）
5. 我講話和寫東西的習慣是什麼？（語氣、常用詞、避免用什麼、段落長短）
```

## 對照表

| 題 | 落點 |
|---|---|
| 1 手上在跑哪幾件事 | SETUP **§2** → `HUB.md`（四欄草稿，逐條唸給他確認） |
| 2 最想達成什麼 | SETUP **§5** → `北極星.md`（講不出門檻就填「未驗證」，⛔ 不准代填數字） |
