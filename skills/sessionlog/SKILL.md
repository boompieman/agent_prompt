# sessionlog — 對話存取

對話原文**只存在本機這個資料夾**（`Sessionlog/`），不上傳任何地方。
這條是對使用者的承諾，`.gitignore` 也擋掉了——不要繞過它。

涵蓋 **Claude Code** 與 **Codex** 兩個引擎。ChatGPT／Gemini 走 `貼上式問卷.md`。

## §CLI

Windows 上 `python3` 一律改成 `py -3`（見 `機制.md`）。

| 指令 | 做什麼 |
|---|---|
| `python3 ".claude/hooks/extract.py" --doctor` | 只數數量，**不寫任何檔、不傳出去**。回 `discovered`／`in_scope`／`already_saved`／`errors` |
| `python3 ".claude/hooks/extract.py" --sample` | 挑一份清洗好的印出來給使用者看。**判準是訊息數 ≥6** |
| `python3 ".claude/hooks/extract.py" --since-days 30` | 清洗最近 30 天 |
| `python3 ".claude/hooks/extract.py" --month 2026-08` | 清洗某一個月（一次一個月） |
| `python3 ".claude/hooks/extract.py" --write-readme` | 重產 `Sessionlog/README.md` 目錄 |

⚠ **樣本的判準是「訊息數 ≥6」，不是「最近的」。** 最近那份很可能是開了就關的中斷對話
（0822 實測：最近 15 份裡就有一份只有「使用者 2 則／AI 0 則」）。拿那個當樣本，
使用者完全看不出清洗後長什麼樣，你還得自己發現、換一份重來。`--sample` 已經內建這個判準。

**掃描範圍**由 `Sessionlog/.scope` 決定：
- `folder`（預設）— 只收「在這個資料夾裡開的對話」
- `machine` — 整台電腦都收。`install_claude_hook.py install` 會寫成這個

## §足跡掃描

從舊對話裡找「他自己重複在做、跟外部服務有關的事」，產出兩張半表：
**該接的連結器**、**該建的排程**。每條都要附出處。

- **快掃版**（SETUP §3 第 2 步）— 近 2–4 週，出前 3–5 條候選。
  產出拿去墊 §3 第 3、4 步：問「東西放哪」時先講證據
  （「我看到你常在對帳，要不要把 Gmail 接起來讓我幫你盯」），比拿菜單裸問命中率高得多。
- **深掃版**（§4 的「足跡月掃」排程）— 近一月，產完整候選表等他勾；
  做完把 `資料地圖.md` §3「上次足跡掃描」改成當天。

### 五條判準

1. **他自己重複在做** — 同一件事在對話裡出現 ≥2 次。講一次的不算。
2. **答得出「多久做一次」** — 答得出來的才適合變排程；答不出來的只寫成能力。
3. **牽涉到外部服務** — 信箱、行事曆、雲端硬碟、筆記庫、金流、社群平台。
   純粹在本機檔案裡搬東西的，不需要連結器。
4. ⚠ **出現在他產品裡的服務，不算他的工作流。** 他的程式碼 import 了 Stripe SDK，
   不代表他每天在對 Stripe 的帳——那是他做的東西，不是他在做的事。
   要看的是「他本人重複的動作」，不是「他的專案依賴什麼」。
5. **每條附出處** — 哪一份 `Sessionlog/*.md`、他原話怎麼講的。
   附不出出處的候選就不要出；那是你猜的，不是掃到的。

### 產出格式

```
候選（連結器）
| 服務 | 為什麼 | 出處 |
|---|---|---|
| Gmail | 他提過三次在對訂閱帳單 | 2026-08-14-claude-…md「每個月都要翻信箱找發票」 |

候選（排程）
| 做什麼 | 多久一次 | 綁定能力 | 出處 |
|---|---|---|---|
```

一條一條讓他勾。⛔ 不要勾完就自己建——排程要走 SETUP §4 的六步。
