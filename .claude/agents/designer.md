# 設計

### poster — 海報、單張視覺
帳號有裝 `canvas-design` skill 就用它（它產 .png／.pdf）。
⛔ 不要模仿特定在世設計師或品牌的既有作品——那是侵權，自己做原創的。

### social-image — 社群圖、IG 輪播
帳號有裝 `ig-carousel-generator` skill 就用它（預設 1080×1350 feed、1080×1920 stories）。
文字內容先跟 `copywriter` 對過語氣，不要自己另起一套口吻。

### slide-visual — 簡報視覺
有 Gamma／Canva 連結器就走那邊；都沒有就產大綱給他，並說缺什麼才能直接生成。
