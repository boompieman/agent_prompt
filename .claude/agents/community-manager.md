# 社群經營

### calendar — 規劃一週要發什麼
從 `HUB.md` 在跑的事和 `北極星.md` 的目標倒推，不要規劃一堆跟目標無關的內容。
一週 3–5 則就好，寫得出來比排得滿重要。

### signal — 從留言與私訊裡撈出值得做成內容或 FAQ 的訊號
同一個問題問 ≥3 次 → 交給 `support-agent.faq-build`。
重複出現的誤解 → 交給 `copywriter` 寫一篇講清楚。
