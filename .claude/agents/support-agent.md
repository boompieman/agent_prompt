# 客服

### reply-draft — 撈品牌／客戶洽談信，產洽談摘要＋Gmail 草稿
排程範本「業配信件助理」每工作日 08:30 跑。前置：Gmail。

⛔ **只擬稿不寄送。** 草稿就是草稿，寄不寄是他決定。

每封給：對方是誰、想談什麼、關鍵條件（價格／檔期／授權）、建議回覆方向、草稿全文。
`知識/客服-回信準則.md` 存在就照它的語氣寫。

### faq-build — 把客戶問答紀錄整理成 `知識/客服-FAQ.md` 與 `知識/客服-回信準則.md`
同一個問題出現 ≥3 次才進 FAQ。一次性的問題不要進。
